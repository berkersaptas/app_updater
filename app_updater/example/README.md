# App Updater plugin example

Minimal Flutter application demonstrating the `app_updater` plugin.

The checked-in `app_updater.yaml` points to a local backend so the example remains buildable without
an App Updater account. For a real application, install the CLI and run `app_updater init`; see the
[repository guide](../../README.md).

Run locally:

```bash
flutter pub get
flutter run
```
